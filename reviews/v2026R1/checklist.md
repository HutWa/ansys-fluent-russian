# Чек-лист визуальной проверки окна Fluent

Для каждого окна проверяйте только применимые пункты. Если для проверки пришлось бы изменить модель, условия, материалы или пользовательский case, отметьте пункт как `not_applicable` и объясните это в `issues`.

- [ ] Заголовок окна переведён.
- [ ] Вкладки переведены.
- [ ] Кнопки и команды переведены.
- [ ] Подписи полей переведены.
- [ ] Значения ComboBox выглядят корректно.
- [ ] Нет внутренних цепочек вида `Group/Subgroup/Value`.
- [ ] Нет обрезанного текста.
- [ ] Термины совпадают с `dictionary/glossary_ru.json`.
- [ ] Имена пользовательских зон, материалов, фаз и поверхностей сохранены.
- [ ] Оставшиеся английские строки перечислены в `issues`.

Фиксируйте версию Fluent, дату, пакет и область проверки. `mesh_only` означает, что была загружена только сетка: это визуальная проверка интерфейса, а не проверка физической модели.

# Русская локализация Ansys Fluent

Неофициальный открытый проект русификации интерфейса Ansys Fluent. Репозиторий содержит собственные переводы, глоссарий, каталоги и инструменты сборки. Проприетарные файлы Ansys сюда не добавляются.

## Текущий прогресс

Актуально для каталога `translations/v2026R1/catalog.json`:

| Состояние записи | Количество |
|---|---:|
| Переведено (`translated`) | **5 009** |
| Требует контекста (`needs_context`) | 651 |
| Требует редакторской проверки (`needs_review`) | 218 |
| Не переводится: идентификаторы и служебные значения (`do_not_translate`) | 547 |
| Всего записей в каталоге | **6 425** |

Таким образом, переводом покрыто **78,0 % записей текущего каталога**. Эта цифра не означает готовность русификации всего Fluent: каталог пока охватывает лишь часть модулей программы, а записи с `needs_context` и `needs_review` намеренно не засчитываются как завершённый перевод.

Поддерживается версия **Fluent Student 2026 R1** в экспериментальном режиме. Русские Qt-каталоги успешно загружались в Fluent; результаты проверки конкретных окон и остающиеся английские строки ведутся отдельно в [журнале визуальной проверки](docs/VISUAL_REVIEW_20260905.md).

## Что уже сделано

- Каталог переводов для 2026 R1 и проверка его структуры.
- Сборка `.qm`-модулей из открытого каталога без хранения файлов Ansys в Git.
- Скрипты безопасной установки с резервной копией и откатом.
- Глоссарий CFD-терминов для единообразного перевода.
- Первичные переводы модулей сетки, решателя, моделей фаз и компонентов, свойств инжекций и ряда граничных условий.

## Быстрый старт

Для установки и запуска Fluent с русским языком используйте инструкции:

- [Установка и откат — RU](docs/INSTALLATION_RU.md)
- [Installation and rollback — EN](docs/INSTALLATION_EN.md)

Перед установкой новой сборки Fluent должен быть закрыт: установщик создаёт резервную копию исходных файлов.

## Для участников

1. Ознакомьтесь с [руководством по переводу](docs/TRANSLATION_GUIDE.md), [глоссарием](dictionary/glossary_ru.json) и [правилами участия](docs/CONTRIBUTING.md).
2. Работайте с каталогом нужной версии в `translations/vYYYYRN/`.
3. Не меняйте поле `source`: для составных Qt-ключей переводится только подтверждённая отображаемая часть.
4. Перед отправкой изменений выполните:

   ```powershell
   python scripts/validate_translation.py translations/v2026R1
   python -m unittest discover -s tests -q
   python scripts/check_repository.py
   ```

Проверка репозитория не допускает типичные бинарные файлы Ansys и файлы крупнее 20 MiB. Она запускается и в GitHub Actions для Pull Request.

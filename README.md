# Ansys Fluent Russian Localization

Неофициальная русская локализация интерфейса Ansys Fluent, создаваемая сообществом. Проект содержит только собственные переводы, словари, патчи и скрипты; проприетарные файлы Ansys в репозиторий не добавляются.

> **Статус:** подготовка инфраструктуры. Первая целевая ветка перевода — Fluent 2026 R1.

## Цели

- Точный и единообразный CFD-перевод пользовательского интерфейса.
- Раздельные наборы переводов для каждой версии Fluent.
- Безопасные установка, откат и проверка локализации.
- Открытая совместная разработка без распространения контента Ansys.

## Быстрый старт для разработчика

1. Клонируйте репозиторий.
2. Изучите [руководство по переводу](docs/TRANSLATION_GUIDE.md) и [правила участия](docs/CONTRIBUTING.md).
3. Храните переводы конкретной версии в `translations/vYYYYRN/`.
4. Перед Pull Request запустите `python scripts/validate_translation.py translations/v2026R1`.

Инструкции для пользователя будут дополнены после определения реального формата ресурсных файлов Fluent 2026 R1: [RU](docs/INSTALLATION_RU.md) · [EN](docs/INSTALLATION_EN.md).

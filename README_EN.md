# Ansys Fluent Russian Localization

An unofficial community Russian localization for the Ansys Fluent user interface. This repository contains only community-authored translations, dictionaries, patches, scripts, and documentation. It must not contain proprietary Ansys files.

> **Status:** infrastructure preparation. Fluent 2026 R1 is the first target.

See the Russian README for the current project outline. Installation instructions will be finalized after the actual Fluent 2026 R1 resource format is inspected.

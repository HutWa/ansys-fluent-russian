# Установка

Инструкция будет завершена после проверки структуры ресурсов Fluent 2026 R1 на локальной установке пользователя.

Планируемый установщик всегда работает в режиме предварительного просмотра (`--dry-run`) по умолчанию, создаёт резервные копии и записывает манифест только в каталог резервного копирования. Он не должен удалять оригинальные файлы.

# Поддерживаемые версии

| Fluent | Статус | Формат ресурсов | Примечание |
|---|---|---|---|
| 2026 R1 | Экспериментальная поддержка | Qt `.qm` / `.ts` | Полный пакет из 553 `.qm` собирается; каталог `ru` и запуск через `lang=ru` подтверждены runtime-тестами, визуальная проверка полной сборки продолжается |

Наборы переводов из разных версий не считаются совместимыми без проверки исходных строк и формата файлов.

## Проверенные модули 2026 R1

- `DisplayProperties`
- `MeshDisplay`
- `MeshColors`
- `GridColors`
- `DisplayOptions`
- `TaskPage_Display_SelectionOptions`
- `TaskPage_General` — базовые параметры решателя и сетки
- `TaskPage_Materials` — базовые команды управления материалами
- `PanelName` — заголовки окон сетки
- `Scene` — подпись прозрачности
- `fluent` — выбранные общие подписи и кнопки

Этот список относится к раннему runtime-проходу. Проверка модуля означает, что созданный проектом `.qm` был собран, установлен и визуально проверен в Fluent Student 2026 R1. Она не означает полного перевода всех строк исходного модуля или визуальную проверку полной текущей сборки.

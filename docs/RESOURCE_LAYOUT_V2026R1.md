# Структура ресурсов Fluent 2026 R1

Документ описывает результаты чтения локальной установки Ansys Student 2026 R1. Абсолютный пользовательский путь и оригинальные ресурсы Ansys в репозитории не сохраняются.

## Подтверждено

- Каталог выпуска: `v261`.
- Ядро Fluent: `fluent26.1.0`.
- Основная локализация интерфейса Fluent хранится в Qt-каталогах `.qm` внутри `cortex/resources/language/{locale}`.
- Обнаружены штатные каталоги `ja`, `ko`, `zh`: соответственно 559, 557 и 557 модулей.
- Наборы модулей между штатными локалями различаются, поэтому один каталог нельзя считать универсальным эталоном полноты.
- Штатный Qt 5.15 `lconvert.exe` успешно преобразует отдельный `.qm` в редактируемый `.ts`; `lrelease.exe` доступен для обратной сборки.
- Глобальная настройка языка хранится в `commonfiles/Language/languagesettings.txt` в виде `lang=en-us`.
- Fluent выбирает локализацию по переменной окружения `lang`. Значение `lang=ru` загружает проектные каталоги из `cortex/resources/language/ru`.
- Runtime-тест подтвердил загрузку `DisplayProperties.qm` и `MeshDisplay.qm`: переведённые строки отображаются в окне Mesh Display.

## Проверенный способ запуска

Перед запуском Fluent дочернему процессу нужно задать `lang=ru`. Переменная `AWP_LOCALE261` для выбора языка GUI не подходит. Общий `languagesettings.txt` менять не требуется. Проектный `scripts/launch_fluent.py` задаёт переменную только запускаемому процессу и не изменяет системное окружение или конфигурацию Ansys.

Это соответствует [официальному руководству Fluent по локализации GUI](https://ansyshelp.ansys.com/public/Views/Secured/corp/v251/en/flu_ug/flu_ug_sec_gui_localization.html), где для штатных локалей используются значения `lang=ja`, `lang=ko` и `lang=zh`.

## Безопасный рабочий процесс

1. Извлекать только выбранные модули во временный локальный файл `*.extracted.json`.
2. Не коммитить исходные `.qm`, промежуточные `.ts` и полный автоматический дамп строк.
3. Переносить в проектный каталог только обрабатываемый блок с переводами и служебным контекстом.
4. Собирать русские `.qm` из материалов проекта.
5. Перед тестом создавать резервную копию и устанавливать только созданный проектом каталог `ru`.

Сборка выполняется во внешнюю staging-папку командой `python scripts/build_translation.py`. Скрипт запрещает прямую сборку внутри установки Fluent и создаёт манифест с SHA-256 каждого полученного `.qm`.
